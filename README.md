# 🚀 CloudVault

### 🔐 Secure Cloud Storage & Management Web App

CloudVault is a modern, secure, and responsive web application that allows users to store, manage, and access their data seamlessly in the cloud. Built using React and Firebase, it ensures real-time updates, authentication, and a smooth user experience.

---

## 🌐 Live Demo

👉 https://pawanyadav3714.github.io/hackathon2/

---

## 📌 Overview

CloudVault is designed to provide a simple yet powerful cloud storage experience. Users can securely authenticate, upload/manage data, and access it anytime from anywhere.

---

## ✨ Features

* 🔐 **Authentication System**

  * Google Sign-In
  * Email & Password Login

* ☁️ **Cloud Storage**

  * Store and manage user data securely

* ⚡ **Real-Time Sync**

  * Instant updates using Firebase

* 📱 **Responsive Design**

  * Works on mobile, tablet, and desktop

* 🔒 **Secure Access**

  * Protected routes & user sessions

## 🔧 Firebase Setup

1. Go to Firebase Console

2. Create a new project

3. Enable Authentication:

   * Google
   * Email/Password

4. Create Firestore Database

5. Add config in your project:

```js id="3pq5lf"
const firebaseConfig = {
  apiKey: "YOUR_API_KEY",
  authDomain: "YOUR_DOMAIN",
  projectId: "YOUR_PROJECT_ID",
  storageBucket: "YOUR_BUCKET",
  messagingSenderId: "YOUR_ID",
  appId: "YOUR_APP_ID"
};
```
